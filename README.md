# Распорядок дня

Чек-лист дел с напоминаниями по времени: повторяются, пока дело не отмечено. Работает в браузере на ПК и как приложение на Android.

- **Веб-версия (она же тестовая на ПК):** https://ripsanches.github.io/denj/
- **APK для телефона:** [последний релиз](https://github.com/ripsanches/denj/releases/latest) → `denj.apk`

## Как устроено

| Папка | Что внутри | Что нужно после изменения |
|---|---|---|
| `docs/` | интерфейс и логика (HTML/CSS/JS) | ничего: телефон подхватит при следующем открытии |
| `android/`, `shell/`, `capacitor.config.json` | Android-оболочка: уведомления, звуки, разрешения | переустановить APK из нового релиза |

Данные (дела, обои, настройки) хранятся в Firebase Firestore, проект `denj-rip`, у каждого пользователя свои.
APK собирается автоматически в GitHub Actions при изменении оболочки.
